
1.Обработка отключения сервера:
В поток приёма сообщений (`ReceiveThread`) добавлен сигнал `connection_lost`. Получение данных обёрнуто в блок `try/except`. Если сервер закрылся или произошёл сбой сети, поток отправляет сигнал в интерфейс и останавливает чтение. В окне программы (`MainWindow`) выводится уведомление об обрыве, а поля ввода блокируются.

2.Безопасная остановка отправки:
В поток отправки (`SendThread`) добавлен метод `stop()`, который отправляет значение `None` в очередь сообщений. Поток считывает `None`, выходит из цикла ожидания и завершает работу. При закрытии окна (`closeEvent`) поток отправки останавливается штатно, не зависая в системе.

3. Индикатор подключения:
Добавлен текстовый статус над чатом. При старте и успешной работе показывает зелёную надпись `Connected`. При потере связи переключается на красную надпись `Disconnected`.
